# Halle Milano — First Real W Motion Test

Source URL:

https://www.hallemilano.com/

## Evidence-driven direction

The test uses the official Halle homepage, Team, Pricelist, Halle Zine and RAUM pages as primary sources.

A secondary Treatwell listing is used only to support the physical location.

## Selected concept

**Between States**

Halle's own community manifesto describes the brand through contrasts such as minimalist/punk, global/local and business/party.

The hero turns that idea into kinetic typography.

## Hero moment

At approximately 56% scroll progress, opposing category words converge and disappear into a single stable HALLE lockup.

## Renderer

Motion 2D.

Reason:

The concept is editorial and typographic. 3D would add technical spectacle without improving the core metaphor.

## Conversion

Primary CTA:

**Book Now**

The CTA links to the WhatsApp destination exposed by the current official site.

## Production note

This first test intentionally uses procedural typography rather than client photography so the complete preview can run without copying or downloading client-owned image assets.

A later production pass can introduce approved Halle Zine or campaign photography while preserving the same concept.
